# Huttak (후딱)

웹페이지를 **내 기기 안에서** 번역하는 한국어용 Chrome 확장입니다. 계정이 없고, 광고와 유료 기능이 없습니다. 기본 번역은 브라우저 안의 [PLaMo 3 Translate](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF)가 합니다.

[Sakutto](https://github.com/jammaru/sakutto)를 포크해 한국어에 맞게 고친 비공식 확장입니다. Preferred Networks, Inc. 및 jammaru와 무관합니다. **Built with PLaMo.**

이 설명은 저장소 `main`의 **v1.2.0** 동작입니다.

## 설치

Chrome 116 이상, Node.js 24, pnpm 12가 필요합니다. 번역 런타임은 처음 한 번 Docker로 만듭니다. 용량과 시간은 [docs/BUILDING.md](docs/BUILDING.md)를 보세요.

```bash
pnpm install
pnpm build:wllama   # 처음 한 번. Docker 필요
pnpm verify:wllama
pnpm build          # 결과는 .output/chrome-mv3
```

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 저장소의 `.output/chrome-mv3` 폴더를 고릅니다.

설치할 때 모든 사이트 접근 권한을 묻지 않습니다. `http`와 `https` 페이지만 번역할 수 있고, `chrome://` 페이지는 대상이 아닙니다.

## 처음 켜기

1. 도구 모음의 Huttak 아이콘을 누릅니다.
2. 시작 안내에서 **라이선스에 동의하고 시작**을 누릅니다. PLaMo Community License입니다.
3. 기본 모델(PLaMo 3 Translate 0.8B, 573MB)을 Hugging Face에서 받습니다. 받는 동안 페이지는 원문 그대로입니다.
4. 준비가 끝나면 영어 페이지를 열고 **이 페이지 번역** 또는 **게시글만 번역**을 누릅니다.
5. 같은 버튼을 한 번 더 누르면 원문입니다.

모델이 준비되기 전에는 페이지 번역 버튼이 기다립니다. 진행은 시작 안내에서 볼 수 있습니다. 모델을 받은 뒤 PLaMo 번역에는 인터넷이 필요 없습니다.

일부 기기에서는 팝업이 더 정확한 모델(2B, 약 1.81GB)을 제안합니다. 제안이 없어도 기본 0.8B로 번역합니다.

## 쓰는 법

팝업에서 이 사이트의 번역 언어와 보기 방식을 바꿉니다. 번역 엔진, 용어집, 모델을 메모리에서 내리는 시간은 **설정 열기**에 있습니다.

입력 칸, 검색창, 비밀번호 칸, 코드 블록은 페이지 본문으로 번역하지 않습니다.

### 페이지 전체와 게시글만

|                 | 페이지 전체        | 게시글만          |
| --------------- | ------------------ | ----------------- |
| 팝업            | **이 페이지 번역** | **게시글만 번역** |
| Windows / Linux | Alt+A              | Alt+P             |
| Mac             | Option (⌥)+A       | Option (⌥)+P      |
| 페이지 우클릭   | 이 페이지 번역     | 게시글만 번역     |

같은 동작을 한 번 더 하면 원문입니다. 한쪽이 켜진 상태에서 다른 쪽을 누르면 그 범위로 바뀝니다.

**게시글만**은 본문을 번역하고, 메뉴, 사이드바, 바닥글, 댓글 창은 그대로 둡니다. X에서는 트윗 글과 아티클 본문을 번역하고, 이름·시간·숫자·옆의 트렌드는 그대로 둡니다. 일반 글과 블로그 본문도 대상입니다.

화면은 한국어인데 글만 영어인 경우, 글의 언어를 보고 설정한 번역 언어로 옮깁니다. 번역한 뒤에도 그 글의 원래 언어를 기억해서 방향이 뒤집히지 않습니다.

게시글이나 본문을 찾지 못하면 안내만 보여 주고, 페이지의 다른 글은 바꾸지 않습니다. 그때는 페이지 전체를 쓰면 됩니다.

페이지에서 글을 선택하지 않고 오른쪽 버튼을 누르면 페이지 메뉴가 나옵니다. 글을 선택한 뒤의 메뉴는 아래 「선택한 글」입니다.

### 단축키

| 동작                           | Windows / Linux | Mac          |
| ------------------------------ | --------------- | ------------ |
| 페이지 번역, 또는 원문         | Alt+A           | Option (⌥)+A |
| 게시글만 번역, 또는 원문       | Alt+P           | Option (⌥)+P |
| 원문 바꾸기 ↔ 원문과 함께 보기 | Alt+B           | Option (⌥)+B |
| 선택한 글                      | Alt+S           | Option (⌥)+S |
| 입력한 글 (입력 번역 화면)     | Ctrl+Enter      | ⌘+Enter      |
| 내가 쓴 한글 (자연스러운 영어) | Ctrl+Enter      | ⌘+Enter      |

키는 `chrome://extensions/shortcuts`에서 바꿀 수 있습니다. Mac의 Chrome은 확장 단축키의 Alt를 Option으로 읽습니다. Alt+D는 쓰지 않습니다. Windows와 Linux의 Chrome이 주소창에 쓰기 때문입니다.

기본 보기 방식은 **원문 바꾸기**입니다. **원문과 함께 보기**는 이 사이트에 기억됩니다. 번역 중에는 팝업과 페이지에 진행이 나옵니다.

### YouTube와 X 자막

페이지 번역이나 게시글 번역이 **켜져 있는 동안**, YouTube와 X에서 자막 파일을 읽어 영상 위에 번역을 띄웁니다. 원문으로 되돌리면 자막 번역도 멈춥니다.

- 자막 파일이 없는 영상은 번역하지 않습니다. 영상에 구워 넣은 글자는 읽지 않습니다.
- YouTube 자동 자막은 한 구절이 모이면 번역하고, 다음 줄이 준비될 때까지 그 줄을 유지합니다. 플레이어 자막 창은 가립니다.
- X는 자막 파일이 조금 늦게 준비되어도 읽습니다. 파일을 읽은 뒤에는 플레이어가 그린 자막을 가리고, 번역한 줄을 보여 줍니다.
- 자막이 이미 번역하려는 언어이면 그대로 둡니다.

### 선택한 글

글을 고른 뒤 Alt+S(Mac은 Option+S)를 누르거나, 오른쪽 버튼의 **선택한 글 번역**을 누릅니다.

글을 드래그하면 옆에 ㅎ 아이콘이 뜨고, 누르면 바로 번역합니다. 기본 설정에서는 그 탭에서 확장을 한 번 부른 뒤부터 뜹니다(팝업, 단축키, 오른쪽 메뉴, 「이 사이트 항상 번역」).

설정의 **모든 사이트에서 드래그 번역 아이콘 보이기**를 켜면 모든 사이트 접근 권한을 받아, 어느 페이지에서든 드래그만으로 아이콘이 뜹니다. 켜기 전에 열어 둔 페이지는 새로고침해야 하고, 끄면 권한을 돌려줍니다.

### 입력한 글

팝업이나 설정의 **입력한 글 번역**을 누르면, 글을 붙여 넣어 번역하는 화면이 열립니다. 페이지 번역과 같은 엔진과 같은 번역 언어를 쓰고, **복사**로 결과를 가져갑니다. 한 번에 10만 자까지입니다. 이 화면은 PLaMo만 쓰고, PLaMo가 지원하지 않는 언어는 받지 않습니다.

### 내가 쓴 한글

팝업이나 설정의 **내가 쓴 한글, 자연스러운 영어**를 누르면, 직접 쓴 한글을 넣는 화면이 열립니다. 뜻을 그대로 옮긴 딱딱한 영어가 아니라, 미국 사람이 그 상황에서 쓸 법한 문장으로 바꿉니다. 페이지 전체 번역, 게시글만 번역, 그리고 위의 입력한 글 번역과는 다른 입력입니다. 계정은 필요 없고, 글은 이 기기 밖으로 나가지 않습니다. 기본은 브라우저 안의 PLaMo이고, 설정에서 이 컴퓨터의 로컬 서버를 켜 두었다면 그 서버가 같은 일을 합니다. **복사**로 영어를 가져갑니다.

### 이 사이트 항상 번역

팝업의 **이 사이트 항상 번역**을 켜면 그 사이트를 열 때마다 페이지 전체를 번역합니다. 그때 그 사이트의 접근 권한을 묻습니다. 모든 사이트를 한 번에 허용하지는 않습니다.

## 번역 엔진

설정 화면의 **번역 엔진**에서 고릅니다.

### 브라우저 안의 PLaMo (기본)

별도 프로그램이 없습니다. PLaMo 3 Translate 0.8B를 브라우저 안에서 돌립니다. 기본 설정에서는 5분 동안 쓰지 않으면 메모리에서 내립니다. 이 시간은 설정에서 바꿀 수 있습니다.

로컬 서버는 기본으로 꺼져 있습니다. 그 상태에서는 서버의 메모리를 쓰지 않습니다.

### 이 컴퓨터의 로컬 서버 (llama.cpp)

[llama.cpp](https://github.com/ggml-org/llama.cpp)의 `llama-server`를 이 컴퓨터에서 켜 두고, 확장이 그 서버로 번역을 요청합니다. 주소는 이 컴퓨터만 받습니다(`127.0.0.1`, `localhost`, `[::1]`). 페이지 글은 기기 밖으로 나가지 않습니다. 이 엔진을 고를 때만 `http://127.0.0.1/*`, `http://localhost/*` 접근 권한을 요청합니다. 이 엔진을 쓰는 동안 확장은 PLaMo를 불러오지 않고, 메모리는 사용자가 켠 서버가 모델 크기만큼 씁니다.

설정에 적힌 예는 다음과 같습니다. 모델 파일은 확장에 들어 있지 않습니다.

```bash
llama-server -m translategemma-12b-it.Q4_K_M.gguf --port 8080
```

서버를 켠 뒤 주소(기본 `http://127.0.0.1:8080`)를 확인하고 **연결 확인**을 누릅니다.

- 서버의 채팅 템플릿을 보고 TranslateGemma인지 판단해, 그 모델 전용 형식으로 보냅니다.
- 일반 대화형 모델(Kanana, Qwen3 등)에는 짧은 번역 지시문을 보냅니다. 소형 모델이 자주 틀리는 말(요일, 대시보드 같은 IT 용어)은 기본 한국어 용어집으로 고정하고, 결과에 영어 요일이 남으면 한국어로 고칩니다. 내 용어집이 우선합니다.
- 로컬 서버로 번역한 문장에는 「이 컴퓨터의 로컬 모델이 만든 기계 번역입니다.」라고 표시합니다.

로컬 서버를 쓰면 PLaMo를 받지 않아도 번역을 시작할 수 있습니다. 그 모델의 라이선스는 모델마다 다릅니다. PLaMo 라이선스와는 별개입니다.

## Mac에서 고른 글

저장소에 Mac 메뉴 막대 앱이 있습니다. Chrome 확장을 바꾸지 않습니다. Mac App Store에도 올리지 않습니다.

앞쪽 앱에서 고른 글을 손쉬운 사용으로 읽고, 확장과 같은 PLaMo로 이 Mac 안에서 번역합니다. 영어는 한국어로, 한국어는 영어로 갑니다. 번역은 원문 글자 위를 덮습니다. 다른 앱의 글자 자체를 바꾸지는 않습니다. 앱이 선택 위치를 알려 주지 않을 때만 옆 패널에 결과를 띄웁니다.

```bash
pnpm mac
```

`pnpm install`을 해 둔 저장소 루트에서 실행합니다. Node.js 24 이상과 CMake가 필요합니다. Chrome 확장을 빌드하거나 다시 불러오지 않습니다. 처음 한 번은 llama.cpp를 이 Mac에서 컴파일하고, 처음 번역할 때 PLaMo 모델을 `~/Library/Application Support/Huttak/models/`에 받습니다.

1. 다른 앱에서 글을 드래그합니다.
2. 옆에 뜨는 **ㅎ**을 누릅니다. 단축키는 **⌃⌥S**입니다. 확장의 Option+S와는 다릅니다.
3. 처음이면 **동의하고 번역**을 누릅니다.
4. 덮개 밖을 누르거나 Esc를 누르면 원문이 다시 보입니다.

**손쉬운 사용**은 필수입니다. **화면 및 시스템 오디오 녹음**은 선택이며, 켜면 원문 주변의 배경색과 글자색으로 덮개를 그립니다. 찍은 화면은 색을 읽는 데만 쓰고 저장하지 않습니다.

권한, 서명, 다시 빌드하는 법은 [macos/README.md](macos/README.md)에 있습니다.

## 언어

PLaMo 3 Translate는 53개 언어를 양방향으로 번역합니다. 원문 언어는 페이지에서 감지합니다. 번역할 언어의 기본값은 Chrome 표시 언어이고, 그 언어가 53개에 없으면 한국어입니다. 페이지가 이미 그 언어이면 한국어 페이지는 영어로, 그 밖의 페이지는 한국어로 갑니다. 팝업에서 이 사이트만 다른 언어로 정할 수 있습니다.

일본어로 번역할 때는 설정의 **일본어 말투**에서 **정중체 (です・ます)**와 **평서체 (だ・である)**를 고릅니다. 설정에는 용어집도 있습니다. 페이지에 나온 말만 번역에 넣습니다.

PLaMo가 지원하지 않는 11개 언어(cs, da, el, fi, kn, no, pt, ro, sv, tr, uk)는 페이지에서만 Chrome 기본 번역기로 번역합니다. 그 언어 팩은 Chrome이 받습니다.

화면 언어는 영어, 일본어, 한국어입니다. Chrome 표시 언어를 따릅니다.

## 개인정보

번역은 내 기기 안에서 합니다. 계정, 광고, 사용 기록 수집이 없습니다. 개발자는 페이지 글, 선택한 글, 용어집, 번역 결과를 받지 않습니다.

확장이 직접 받는 파일은 Hugging Face의 PLaMo 모델입니다. 로컬 서버 엔진을 고르면 이 컴퓨터의 서버로만 요청합니다. 설정에서 모델과 번역 캐시를 지울 수 있습니다.

자세한 내용은 [PRIVACY.ko.md](PRIVACY.ko.md)에 있습니다. 원본 Sakutto의 영어·일본어 문서는 [PRIVACY.md](PRIVACY.md)에 있습니다.

## Sakutto와 다른 점

같은 문장을 기본 엔진(브라우저 안의 PLaMo 0.8B)으로 번역하면 품질은 같습니다. 차이는 누구를 위한 번역기냐입니다.

| 구분                  | Sakutto                          | Huttak                                                              |
| --------------------- | -------------------------------- | ------------------------------------------------------------------- |
| 기본 언어쌍           | 일본어↔영어                      | **한국어↔영어**                                                     |
| 이미 그 언어인 페이지 | 일본어 페이지 → 영어             | 한국어 페이지 → 영어                                                |
| 화면 언어             | 영어·일본어                      | 영어·일본어·**한국어**                                              |
| 맞춤                  | 일본어 출력으로 속도 측정·워밍업 | 한국어 출력으로 속도 측정·워밍업, 영어 UI 문구를 한국어로 미리 번역 |
| 번역 엔진             | PLaMo(브라우저)                  | PLaMo(브라우저, 기본) + **로컬 llama.cpp 선택**                     |
| 공개                  | Chrome 웹 스토어                 | 아직 미등록. 직접 설치                                              |

## 빌드와 개발

설치에 필요한 명령은 [설치](#설치)에 있습니다. `pnpm build:wllama`는 고정된 wllama 커밋 `d275dac`를 `emscripten/emsdk:4.0.20` 컨테이너 안에서 컴파일합니다. wasm, worker, 모델 가중치는 커밋하지 않습니다. 이 빌드를 확인하기 전에는 `pnpm build`와 `pnpm zip`이 실행되지 않습니다.

```bash
pnpm dev            # 개발용 빌드
pnpm lint
pnpm typecheck
pnpm test
pnpm test:e2e       # 로컬 테스트 페이지. 모델을 받지 않음
pnpm zip            # .output에 Chrome 웹 스토어용 zip. 스토어에 올리는 명령은 아닙니다
```

`pnpm bench:mock`과 `pnpm bench:live`는 [bench/pages](bench/pages)의 고정 페이지 8개로 페이지 전체 번역 속도를 잽니다. 자세한 내용은 [bench/README.md](bench/README.md)를 보세요.

## 권한

| 권한               | 요청하는 이유                                                        |
| ------------------ | -------------------------------------------------------------------- |
| `storage`          | 번역 언어, 보기 방식 등 설정을 저장합니다.                           |
| `unlimitedStorage` | 받은 모델과 번역 캐시를 기기에 보관합니다.                           |
| `offscreen`        | 서비스 워커보다 오래 사는 문서에서 번역 런타임을 돌립니다.           |
| `activeTab`        | 팝업을 열거나 명령을 쓴 뒤 현재 페이지를 읽습니다.                   |
| `scripting`        | 번역을 요청하면 현재 탭에 콘텐츠 스크립트를 넣습니다.                |
| `contextMenus`     | 오른쪽 메뉴에 페이지 번역, 게시글만 번역, 선택한 글 번역을 넣습니다. |

선택 권한은 세 경우에만 묻습니다. 이 사이트 항상 번역, 로컬 서버 엔진, 모든 사이트에서 드래그 아이콘. 설치할 때 모든 사이트 권한을 요청하지 않습니다.
