새 항목으로 등록할 때 Developer Dashboard에 그대로 붙여 넣는 글입니다. 원본 Sakutto의 등록 글은 [CWS_LISTING.md](CWS_LISTING.md)에 있습니다.

## 상세 설명

```text
웹페이지를 내 기기 안에서 번역하는 한국어 사용자용 확장입니다. 영어 페이지는 한국어로, 한국어 페이지는 영어로 번역합니다.

- 페이지 전체 번역, 선택한 글 번역, 직접 입력한 글 번역
- 원문을 바꿔 보여 주는 보기와, 원문과 번역을 함께 보는 보기
- 사이트별 자동 번역, 용어집(CSV 가져오기·내보내기)
- 단축키: Alt+A 페이지 번역, Alt+B 보기 전환, Alt+S 선택한 글 번역 (Mac은 Option)

번역은 PLaMo 3 Translate가 브라우저 안에서 합니다. 페이지 글을 번역 서버로 보내지 않고, 광고와 사용 기록 수집이 없습니다. 처음 쓸 때 PLaMo Community License에 동의하면 모델(약 573MB)을 Hugging Face에서 한 번 받습니다.

원하면 이 컴퓨터에서 돌아가는 llama.cpp 서버(예: TranslateGemma)로 번역하도록 바꿀 수 있습니다. 이때도 이 컴퓨터 주소(127.0.0.1, localhost)로만 요청합니다.

Sakutto(jammaru)를 바탕으로 한 오픈소스(MIT) 포크입니다. 비공식 확장이며 Preferred Networks, Inc. 및 jammaru와 관련이 없습니다. Built with PLaMo.

소스 코드: https://github.com/heomin86/huttak
개인정보 처리방침: https://github.com/heomin86/huttak/blob/main/PRIVACY.ko.md
```

## 권한 사유

설치할 때 요청하는 권한은 아래 6개뿐입니다. 설치 시 `host_permissions`는 비어 있고, 선택 호스트 권한은 `https://*/*`, `http://*/*`입니다.

`storage`

```text
번역 언어, 보기 방식, 번역 엔진, 용어집, 사이트별 규칙, 라이선스 동의 기록을 이 기기의 chrome.storage.local에 저장합니다.
```

`unlimitedStorage`

```text
받은 번역 모델 파일(기본 모델 약 573MB)과 번역 캐시를 이 기기에 보관합니다.
```

`offscreen`

```text
번역 런타임을 서비스 워커보다 오래 유지되는 문서에서 실행합니다. 모델 불러오기와 번역을 그 문서 안에서 합니다.
```

`activeTab`

```text
팝업, 단축키, 마우스 오른쪽 메뉴로 번역을 요청했을 때 열려 있는 탭의 페이지를 읽습니다.
```

`scripting`

```text
번역을 요청한 탭이나 자동 번역을 허용한 탭에 확장에 들어 있는 콘텐츠 스크립트를 넣습니다. 설치할 때 모든 사이트에 넣지 않습니다.
```

`contextMenus`

```text
마우스 오른쪽 메뉴에 「이 페이지 번역」과 「선택한 글 번역」을 추가합니다.
```

선택 호스트 권한 (`https://*/*`, `http://*/*`)

```text
설치할 때는 요청하지 않습니다. 어떤 사이트의 자동 번역을 켤 때 그 사이트만 요청하고, 설정에서 로컬 서버 엔진을 고를 때 이 컴퓨터 주소(http://127.0.0.1/*, http://localhost/*)만 요청합니다.
```

## 원격 코드

「원격 코드를 사용하지 않음」을 고릅니다. 설명 칸이 나오면:

```text
실행 코드(스크립트, worker, wasm)는 모두 패키지에 들어 있습니다. huggingface.co에서는 모델 가중치(GGUF 데이터)만 받고, 공식 저장소 커밋으로 고정해 SHA-256을 확인한 뒤 씁니다. 페이지 글은 요청에 넣지 않습니다.
```
