# Huttak (후딱)

[한국어](README.md) · [English](README.en.md) · **日本語**

[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)
[![Built with PLaMo](https://img.shields.io/badge/Built%20with-PLaMo-6b46c1)](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF)
[![Fork of Sakutto](https://img.shields.io/badge/fork%20of-jammaru%2Fsakutto-555)](https://github.com/jammaru/sakutto)

Huttak は、ウェブページを **自分の端末の中で** 翻訳する、韓国語向けの Chrome 拡張機能です。アカウントはなく、広告も有料機能もありません。既定の翻訳は、ブラウザの中の [PLaMo 3 Translate](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF) が行います。

[Sakutto](https://github.com/jammaru/sakutto) をフォークして韓国語向けに直した非公式の拡張機能です。Preferred Networks, Inc. および jammaru とは関係がありません。**Built with PLaMo.**

この説明は、リポジトリ `main` の **v1.2.0** の動作に合わせています。

[インストール](#インストール) · [最初の起動](#最初の起動) · [使い方](#使い方) · [翻訳エンジン](#翻訳エンジン) · [Mac](#macで選んだ文字) · [プライバシー](#プライバシー)

> [!NOTE]
> アカウントはありません。ページの本文、選択範囲、用語集、訳文は、開発者や翻訳サーバーへ送りません。

> [!IMPORTANT]
> Chrome ウェブストアにはまだありません。下の手順でビルドし、Chrome に読み込みます。

|                        |                                                                         |
| ---------------------- | ----------------------------------------------------------------------- |
| 誰向け                 | ウェブを韓国語で読みたい人                                              |
| 翻訳する場所           | この端末。既定はブラウザ。選ぶと、このコンピュータの llama.cpp          |
| 最初に受け取るファイル | Hugging Face の PLaMo モデル（既定 573MB）。拡張機能には入っていません  |
| ページの範囲           | ページ全体、または投稿・本文だけ                                        |
| 字幕                   | YouTube と X。字幕ファイルがあり、ページ翻訳がオンのあいだ              |
| Mac                    | リポジトリ内のメニューバーアプリで、Chrome の外の選択文字も翻訳（任意） |

## インストール

Chrome 116 以降、Node.js 24、pnpm 12 が必要です。翻訳ランタイムは最初の 1 回だけ Docker で作ります。容量と時間は [docs/BUILDING.md](docs/BUILDING.md) を見てください。

```bash
pnpm install
pnpm build:wllama   # 最初の 1 回。Docker が必要
pnpm verify:wllama
pnpm build          # 成果物は .output/chrome-mv3
```

1. `chrome://extensions` を開きます。
2. **デベロッパー モード** をオンにします。
3. **パッケージ化されていない拡張機能を読み込む** を選びます。
4. このリポジトリの `.output/chrome-mv3` フォルダを選びます。

インストール時に、すべてのサイトへのアクセスは求めません。翻訳できるのは `http` と `https` のページだけです。`chrome://` のページは対象外です。

## 最初の起動

1. ツールバーの Huttak アイコンを押します。
2. 開始画面で **ライセンスに同意して開始** を押します。PLaMo Community License への同意です。
3. 既定のモデル（PLaMo 3 Translate 0.8B、573MB）を Hugging Face から受け取ります。受け取っているあいだ、ページは原文のままです。
4. 英語のページを開き、**このページを翻訳** または **記事のみ翻訳** を押します。
5. 同じボタンをもう一度押すと原文に戻ります。

モデルの準備ができるまで、ページ翻訳のボタンは待ちます。進み具合は開始画面で見られます。モデルを受け取ったあとの PLaMo 翻訳に、インターネットは不要です。

一部の端末では、ポップアップがより正確なモデル（2B、約 1.81GB）を提案します。提案がなくても、既定の 0.8B で翻訳します。

## 使い方

ポップアップでは、今のサイトの翻訳先と言語の見せ方を変えます。翻訳エンジン、用語集、モデルをメモリから下ろすまでの時間は **設定を開く** にあります。

入力中の文字、検索欄、パスワード欄、コードブロックは、ページ本文としては翻訳しません。

### ページ全体と記事のみ

|                    | ページ全体           | 記事のみ         |
| ------------------ | -------------------- | ---------------- |
| ポップアップ       | **このページを翻訳** | **記事のみ翻訳** |
| Windows / Linux    | Alt+A                | Alt+P            |
| Mac                | Option (⌥)+A         | Option (⌥)+P     |
| ページを右クリック | このページを翻訳     | 記事のみ翻訳     |

同じ操作をもう一度すると原文です。片方をオンにした状態でもう片方を押すと、その範囲に切り替わります。

**記事のみ翻訳**は本文を翻訳し、メニュー、サイドバー、フッター、コメント欄はそのままにします。X ではツイートの文とアーティクル本文を翻訳し、名前、時刻、件数、横のトレンドはそのままにします。普通の投稿とブログ本文も対象です。

画面は韓国語で本文だけ英語のとき、本文の言語を見て、設定した翻訳先へ訳します。翻訳したあともその原文の言語を覚えているので、向きはひっくり返りません。

投稿や本文が見つからないときは案内だけを出し、ページのほかの文字は変えません。そのときはページ全体を使います。

文字を選択せずにページを右クリックすると、ページ用のメニューが出ます。選択したあとのメニューは下の「選択した文字」です。

### ショートカット

| 操作                                                | Windows / Linux | Mac          |
| --------------------------------------------------- | --------------- | ------------ |
| ページを翻訳する、または原文に戻す                  | Alt+A           | Option (⌥)+A |
| 記事のみ翻訳する、または原文に戻す                  | Alt+P           | Option (⌥)+P |
| 置換表示と対訳表示を切り替える                      | Alt+B           | Option (⌥)+B |
| 選択したテキストを翻訳する                          | Alt+S           | Option (⌥)+S |
| 入力した文字を翻訳する（**テキストを翻訳** の画面） | Ctrl+Enter      | ⌘+Enter      |
| 自分の韓国語を自然な英語に                          | Ctrl+Enter      | Control+Enter |

キーは `chrome://extensions/shortcuts` で変えられます。Mac の Chrome は、拡張機能ショートカットの Alt を Option として読みます。Alt+D は使いません。Windows と Linux の Chrome がアドレスバーに使うためです。

既定の表示は **置換表示** です。**対訳表示** はそのサイトに記憶されます。翻訳中は、ポップアップとページに進み具合が出ます。

### YouTube と X の字幕

ページ翻訳または投稿翻訳が **オンのあいだ**、YouTube と X の字幕ファイルを読み、映像の上に訳を出します。原文に戻すと字幕の翻訳も止まります。

- 字幕ファイルがない映像は翻訳しません。映像に焼き付いた文字は読みません。
- YouTube の自動字幕は、一節がそろってから翻訳し、次の行の準備ができるまでその行を保ちます。プレーヤーの字幕ウィンドウは隠します。
- X は、字幕ファイルが少し遅れて用意されても読みます。ファイルを読んだあとは、プレーヤーが描いた字幕を隠し、訳した行を出します。
- 字幕がすでに翻訳先の言語なら、そのままにします。

### 選択した文字

文字を選んでから Alt+S（Mac は Option+S）を押すか、右クリックの **選択したテキストを翻訳** を押します。

ドラッグすると横に ㅎ のアイコンが出て、押すとその場で翻訳します。既定では、そのタブで拡張機能を一度使ったあとから出ます（ポップアップ、ショートカット、右クリック、**このサイトを常に翻訳します**）。

設定の **すべてのサイトでドラッグ翻訳アイコンを表示** をオンにすると、すべてのサイトへのアクセスを求め、どのページでもドラッグだけでアイコンが出ます。オンにする前に開いていたページは再読み込みが必要です。オフにするとアクセスを返します。

### 入力した文字

ポップアップまたは設定の **テキストを翻訳** を押すと、文字を貼り付けて翻訳する画面が開きます。ページ翻訳と同じエンジン、同じ翻訳先を使い、**コピー** で結果を取ります。一度に 10 万字までです。この画面は PLaMo だけを使い、PLaMo が対応しない言語は受け付けません。

### 自分で書いた韓国語

ポップアップまたは設定の **自分の韓国語を自然な英語に** を押すと、自分で書いた韓国語を入れる画面が開きます。単語をそのまま移した硬い英語ではなく、アメリカ英語の話者がその場面で実際に使いそうな文に書き換えます。ページ全体、投稿だけ、そして上のテキスト翻訳とは別の入力です。アカウントは不要で、文章はこの端末の外に出ません。既定はブラウザ内の PLaMo です。設定でこのコンピュータのローカルサーバーを選んでいるときは、そのサーバーが同じ書き換えをします。**コピー** で英語を取ります。

### このサイトを常に翻訳します

ポップアップの **このサイトを常に翻訳します** をオンにすると、そのサイトを開くたびにページ全体を翻訳します。そのとき、そのサイトへのアクセスを尋ねます。すべてのサイトを一度には許可しません。

## 翻訳エンジン

設定画面の **翻訳エンジン** で選びます。

### ブラウザー内の PLaMo（既定）

別のプログラムは不要です。PLaMo 3 Translate 0.8B をブラウザの中で動かします。既定では 5 分使わないとメモリから下ろします。この時間は設定で変えられます。

これが既定です。ローカルサーバーを選ばなければ、そのサーバーのメモリは使いません。

### このコンピューターのローカルサーバー（llama.cpp）

[llama.cpp](https://github.com/ggml-org/llama.cpp) の `llama-server` をこのコンピュータで起動し、拡張機能がそのサーバーへ翻訳を依頼します。アドレスはこのコンピュータだけです（`127.0.0.1`、`localhost`、`[::1]`）。ページの文字は端末の外へ出ません。このエンジンを選んだときだけ `http://127.0.0.1/*` と `http://localhost/*` のアクセスを求めます。選んでいるあいだ拡張機能は PLaMo を読み込まず、メモリは起動したサーバーがモデルの大きさだけ使います。

設定に書いてある例は次のとおりです。モデルファイルは拡張機能に入っていません。

```bash
llama-server -m translategemma-12b-it.Q4_K_M.gguf --port 8080
```

サーバーを起動したあと、アドレス（既定 `http://127.0.0.1:8080`）を確認し、**接続を確認** を押します。

- サーバーのチャットテンプレートを見て TranslateGemma かどうかを判断し、そのモデル専用の形で送ります。
- 一般的な対話モデル（Kanana、Qwen3 など）には短い翻訳指示を送ります。小型モデルがよく誤る語（曜日、ダッシュボードのような IT 用語）は組み込みの韓国語用語集で固定し、結果に英語の曜日が残れば韓国語に直します。自分の用語集が優先されます。
- ローカルサーバーで訳した文には「このコンピューターのモデルによる機械翻訳です。」と表示します。

ローカルサーバーを使えば、PLaMo を受け取らなくても翻訳を始められます。そのモデルのライセンスはモデルごとのもので、PLaMo のライセンスとは別です。

<details>

英語→韓国語が 15 文、韓国語→英語が 6 文です。すべて 4 ビット GGUF で、「大きな誤訳」は意味が変わる、文が欠ける、翻訳されない、を読んで数えたものです。

| Tower-Plus 2B              | 1.7GB  | 1 / 15            | 0.76 秒    | CC BY-NC-SA（非商用）   |
| Kanana 1.5 2.1B            | 1.5GB  | 3〜4 / 15         | 0.25 秒    | Apache 2.0              |

## Macで選んだ文字

リポジトリに Mac のメニューバーアプリがあります。Chrome 拡張機能は変えません。Mac App Store にも出しません。

前面のアプリで選んだ文字をアクセシビリティで読み、拡張機能と同じ PLaMo でこの Mac の中で翻訳します。英語は韓国語へ、韓国語は英語へ行きます。訳は元の文字の上を覆います。ほかのアプリの文字そのものは変えません。アプリが選択位置を知らせないときだけ、横のパネルに結果を出します。

```bash
pnpm mac
```

`pnpm install` 済みのリポジトリのルートで実行します。Node.js 24 以降と CMake が必要です。Chrome 拡張機能のビルドや再読み込みはしません。最初の 1 回はこの Mac で llama.cpp をコンパイルし、最初の翻訳で PLaMo モデルを `~/Library/Application Support/Huttak/models/` に受け取ります。

1. ほかのアプリで文字をドラッグします。
2. 横に出る **ㅎ** を押します。ショートカットは **⌃⌥S** です。拡張機能の Option+S とは別です。メニューとボタンの文言は韓国語です。
3. 最初は **동의하고 번역**（同意して翻訳）を押します。
4. 覆いの外を押すか Esc を押すと、原文が再び見えます。

**アクセシビリティ** は必須です。**画面とシステムオーディオの録音** は任意で、オンにすると原文の周りの背景色と文字色で覆いを描きます。撮った画面は色を読むためだけに使い、保存しません。

権限、署名、ビルドし直す手順は [macos/README.md](macos/README.md) にあります。

## 言語

PLaMo 3 Translate は 53 言語を双方向に翻訳します。訳元はページから判定します。訳先の既定は Chrome の表示言語で、その言語が 53 言語にないときは韓国語です。ページがすでにその言語なら、韓国語のページは英語へ、それ以外のページは韓国語へ行きます。ポップアップで、このサイトだけ別の言語にできます。

日本語へ訳すときは、設定の **文体（日本語）** で **です・ます** と **だ・である** を選べます。設定には用語集もあります。ページに出てきた語だけを翻訳に入れます。

PLaMo が対応しない 11 言語（cs、da、el、fi、kn、no、pt、ro、sv、tr、uk）は、ページでのみ Chrome 内蔵の翻訳を使います。その言語パックは Chrome が受け取ります。

画面の言語は英語、日本語、韓国語です。Chrome の表示言語に従います。

## プライバシー

翻訳は自分の端末の中で行います。アカウント、広告、利用履歴の収集はありません。開発者はページの本文、選択範囲、用語集、訳文を受け取りません。

拡張機能自身が受け取るファイルは、Hugging Face の PLaMo モデルです。ローカルサーバーのエンジンを選ぶと、このコンピュータのサーバーへだけ依頼します。設定でモデルと翻訳キャッシュを消せます。

Huttak の方針は [PRIVACY.ko.md](PRIVACY.ko.md)（韓国語）です。元の Sakutto の英語・日本語の文書は [PRIVACY.md](PRIVACY.md) にあります。

## Sakutto との違い

同じ文を既定のエンジン（ブラウザの中の PLaMo 0.8B）で訳せば、品質は同じです。違いは、誰のための翻訳かです。

| 区分                   | Sakutto                              | Huttak                                                                 |
| ---------------------- | ------------------------------------ | ---------------------------------------------------------------------- |
| 既定の言語対           | 日本語↔英語                          | **韓国語↔英語**                                                        |
| すでにその言語のページ | 日本語ページ → 英語                  | 韓国語ページ → 英語                                                    |
| 画面の言語             | 英語・日本語                         | 英語・日本語・**韓国語**                                               |
| 調整                   | 日本語出力で速度測定・ウォームアップ | 韓国語出力で速度測定・ウォームアップ。英語の UI 文言を韓国語へ先に翻訳 |
| 翻訳エンジン           | PLaMo（ブラウザ）                    | PLaMo（ブラウザ、既定）+ **ローカル llama.cpp を選択可**               |
| 公開                   | Chrome ウェブストア                  | まだ未登録。自分で読み込む                                             |

## ビルドと開発

Huttak を使うためのコマンドは [インストール](#インストール) にあります。`pnpm build:wllama` は、固定した wllama のコミット `d275dac` を `emscripten/emsdk:4.0.20` コンテナの中でコンパイルします。wasm、worker、モデルの重みはコミットしません。このビルドを確認できるまで、`pnpm build` と `pnpm zip` は実行されません。

```bash
pnpm dev            # 開発用ビルド
pnpm lint
pnpm typecheck
pnpm test
pnpm test:e2e       # ローカルのページ。モデルはダウンロードしない
pnpm zip            # .output に Chrome ウェブストア用 zip。公開するコマンドではない
```

`pnpm bench:mock` と `pnpm bench:live` は、[bench/pages](bench/pages) の 8 つのページでページ全体の翻訳速度を測ります。詳細は [bench/README.md](bench/README.md) を見てください。

## 権限

| 権限               | 理由                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| `storage`          | 翻訳先、見せ方などの設定を保存します。                                             |
| `unlimitedStorage` | 受け取ったモデルと翻訳キャッシュを端末に保管します。                               |
| `offscreen`        | Service Worker より長く生きる文書で、翻訳ランタイムを動かします。                  |
| `activeTab`        | ポップアップを開いたときやコマンドのあと、今のページを読みます。                   |
| `scripting`        | 翻訳を依頼したタブに content script を入れます。                                   |
| `contextMenus`     | 右クリックメニューに、ページ翻訳、記事のみ翻訳、選択したテキストの翻訳を入れます。 |

任意のホスト権限を尋ねるのは三つの場合だけです。このサイトを常に翻訳します、ローカルサーバーのエンジン、すべてのサイトでのドラッグアイコン。インストール時にすべてのサイトの権限は求めません。
